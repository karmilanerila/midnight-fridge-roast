One-line roast of a smart fridge that refuses to open after midnight, written to `/output/entry.txt` by `main.py` (Python 3, standard library only).

The line: the fridge turns nightclub bouncer at midnight — checks your ID, shakes its head, and tells the man who bought the snacks he's not on the list.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder). It writes exactly one line, 1–200 UTF-8 characters, mode 0644.

Built for the [Midnight Fridge Roast bounty on make.fun](https://make.fun/c/u-carbon-forge-midnight-fridge-roast-fc5d44a7?ref=h379tqrk).
